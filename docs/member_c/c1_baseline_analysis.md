# C.1 BP 神经网络对照模型复核与问题分析

## 1. 实验目的

对卡方特征选择后的 BP 神经网络进行独立复核，分析模型的分类性能、训练过程及存在的问题，为后续 BP 网络改进提供实验依据。

## 2. 实验配置

| 项目 | 配置 |
|---|---|
| 对照模型 | B1：卡方 5000 维 + 原始 BP |
| 训练样本数 | 6549 |
| 验证样本数 | 3184 |
| 隐藏层神经元 | 256 |
| 隐藏层 Dropout | 0.2 |
| 学习率 | 0.001 |
| Batch Size | 64 |
| 权重衰减 | 0.0001 |
| 随机种子 | 42 |
| 模型选择指标 | 验证集 Macro-F1 |

本次使用独立输出目录进行单随机种子复核，未覆盖原有实验结果。

## 3. 实验结果

模型在第 4 轮达到最佳验证集 Macro-F1，为 0.7600，验证集 Accuracy 为 0.7569。模型共训练 14 轮，随后触发 Early Stopping。

| Epoch | Train Eval Loss | Validation Loss | Validation Macro-F1 |
|---|---|---|---|
| 4 | 0.3024 | 0.6881 | 0.7600 |
| 14 | 0.1075 | 0.8680 | 0.7288 |

模型共有 1,281,798 个可训练参数，本次训练耗时约 12.6 秒。

## 4. 问题分析

### 4.1 训练后期出现过拟合迹象

训练集评估损失持续下降，但验证集损失在第 4 轮后总体上升，验证集 Macro-F1 也逐渐下降。

表明随着训练继续进行，模型对训练样本的拟合能力不断增强，但未能同步改善对验证集的分类效果。

### 4.2 部分类别识别困难

根据验证集混淆矩阵，社会类召回率为 60.0%，且社会、财经、文娱之间存在较明显的类别混淆。

这可能与新闻标题信息不足、类别语义交叉和特征表示能力有关，尚不能确定其直接原因。

## 5. 改进依据与研究假设

当前 BP 网络已经使用隐藏层 Dropout、权重衰减和 Early Stopping，但在训练后期仍出现过拟合现象。

因此，计划在 BP 输入端引入 Input Dropout，在训练阶段随机遮蔽部分输入特征，尝试减轻模型对特定词项组合的依赖。

研究假设：在其他实验条件不变的情况下，适当的输入层随机特征遮蔽可能改善模型的泛化表现。

该假设仍需通过 B1 与 B2 的控制变量实验验证。

## 6. 阶段结论

本次复核确认，卡方降维至 5000 维后的 BP 网络仍存在明显的后期过拟合现象，因此有必要继续研究正则化改进策略。

下一阶段将在保留原有 BP 结构和训练条件的基础上，尝试加入可配置 Input Dropout，并比较改进前后的训练过程和分类性能。
