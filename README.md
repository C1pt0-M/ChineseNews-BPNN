# 基于 TF-IDF 特征降维与 BP 神经网络的中文新闻分类研究

课程实验「基于 TF-IDF 特征降维与 BP 神经网络的中文新闻分类研究」的完整实现：
数据采集 → 清洗 → 数据审计 → 时间划分 → 特征工程 → BP 神经网络实验。

数据来源为中国新闻网（中新网）历史滚动新闻归档页，仅采集**标题与元数据**，不采集正文。
当前进度：数据集版本 `1.1.0`，已完成第一轮特征方案对比实验。

## 4. 快速开始

```bash

```

### 4.3 阶段三：正式采集（默认 2025-01-01 ~ 2026-10-31）

```bash
python main.py all --start 2025-01-01 --end 2026-10-31 --max-per-class 2000
```

### 4.4 分步执行

```bash
python main.py crawl --start 2025-01-01 --end 2026-10-31   # 仅采集
python main.py clean --max-per-class 2000                  # 仅清洗+统计+出图
```

### 4.5 断点续采

程序默认续采：已成功采集的日期写入 `state/checkpoint.json`，并在 `state/raw_parts/` 保留逐日切片。
中断后重新执行相同命令即可跳过已完成日期。

```bash
python main.py all --start 2025-01-01 --end 2026-10-31        # 续采（默认）
python main.py all --start 2025-01-01 --end 2026-10-31 --no-resume   # 强制重采
```

> 修改区间后无需手动清理断点：程序按日期粒度判断，区间内的旧日期仍会复用。

## 7. 网页结构要点（实测，勿凭经验修改）

```
div.content_list > ul > li
    ├── div.dd_lm     分类标签，形如 [ 社会 ]；部分为纯文本如 [其他]，无 <a>
    ├── div.dd_bt > a 标题文本 + 文章链接（相对路径）
    └── div.dd_time   发布时间，形如 1-1 23:21（无年份、无补零）
```

四个必须注意的坑：

1. **编码**：响应头未声明 charset（默认被 requests 判为 ISO-8859-1），实际为 UTF-8，必须显式指定，否则中文乱码。
2. **分类取值**：`[其他]` 等标签不含 `<a>`，若用 `div.dd_lm > a` 取值会漏，必须取 `dd_lm` 文本并剥离方括号与空白。
3. **空占位**：列表中存在大量空 `<li></li>`（分隔线），须按「是否有标题链接」过滤，不能按 `<li>` 数量计条数。
4. **无分页**：单页即单日全量；若某日出现 `.pagebox`，程序会告警提示当日可能不完整。

链接形态（均为具体内容页，非栏目首页）：

| 类型 | 形态 | 数字 ID 位数 |
|---|---|---|
| 图文新闻 | `/gj/2025/01-01/10346216.shtml` | 8 |
| 高清图集 | `/tp/hd2011/2025/01-05/1136408.shtml` | 7 |
| 视频 | `/sh/shipin/cns/2025/01-01/news1009460.shtml` | 7（`news` 前缀） |

## 8. 清洗规则

1. 标题规范化：去除零宽字符、BOM、`\r\n`，折叠连续空白，去首尾空格；**不删标点、不改写、不截断**。
2. 删除空标题。
3. 删除非内容页链接（栏目首页、专题页等），仅保留数字 ID 结尾的内容页。
4. 校验发布时间格式，并校验「月-日」与归档日期一致，不一致则记录并剔除。
5. 按规范化 URL 去重（保留首次出现）。
6. 辅助检查 URL 不同但标题完全相同的记录，保留首条并在报告中计数。
7. 类别映射：仅保留映射到目标六类的记录；`unknown`（无分类）一律剔除。
8. `--max-per-class` 配额截断采用按日期等距抽样，避免时间分布偏斜。

## 9. 分类映射说明（重要）

站点滚动列表的原始标签共 20 余种，与目标六类并非一一对应：

| 目标类 | 原始标签 | 说明 |
|---|---|---|
| 财经 | 财经 | 直接对应 |
| 体育 | 体育 | 直接对应 |
| 文娱 | 文化 | 站点不存在「文娱」标签，其文化/文艺内容统一标记为「文化」；**保留「文娱」作为目标类名**，映射为一对一确定性映射，未改动任何单条样本归属 |
| 教育 | 教育 | 直接对应，但属长尾类别 |
| 社会 | 社会 | 直接对应 |
| 国际 | 国际 | 直接对应 |

未纳入的原始标签：`图片`、`视频`（媒体形态而非主题）、`国内`、`时政`、`湾区`、`华人`、
`健康`、`生活`、`理论`、`法治`、`一带一路`、`国是`、`东西问`、`其他` 等。
原始标签全部保留在 `raw_category` 字段与报告第 4 节，便于核查。

> 「文娱」列的语义为**文化/文艺广义范畴**（含影视、文学、舞台艺术、文物考古、非遗等），

> 详见 `reports/data_audit_report.md` 第 3 节。论文方法章节须写明该操作性定义。

> 若需改为其他映射方案，只需修改 `config.py` 中的 `CATEGORY_MAPPING` 与 `TARGET_CATEGORIES`，
> 无需改动采集与清洗逻辑。

## 11. 模型与实验（第一轮）

### 11.1 三种特征处理方案

| 方案 | 做法 | 输出 | 维度 |
|---|---|---|---|
| A | TF-IDF 直接输入 | 稀疏 | 10,864 |
| B | TF-IDF + 卡方特征选择 | 稀疏 | 2,000 / 5,000 / 10,000 |
| C | TF-IDF + TruncatedSVD | 稠密 | 100 / 200 / 300 |

TF-IDF：`min_df=2`、`max_df=0.95`、`sublinear_tf=True`、`max_features=20000`、
`ngram_range=(1,2)`；jieba 精确模式分词。**词表 / 卡方 / SVD / 标准化器均只在
`train.csv` 上 fit**，验证集与测试集只做 transform。

### 11.2 BP 网络

`输入(d) → Linear(256) → ReLU → Dropout(0.2) → Linear(6)`，
CrossEntropyLoss + Adam（lr=1e-3, weight_decay=1e-4），batch 64，
最多 100 轮，验证集 Macro-F1 连续 10 轮无改善即早停。
稀疏输入按 batch 转稠密，不整体 densify。

## 13. 常见问题

**Q：某天返回 404 怎么办？**
该日无归档页（如非法日期 `2025-02-30` 或未归档的未来日期）。程序记入 `crawl_report.json`
的 `days` 列表（`result: not_found`），不重试、不计入错误。

**Q：`教育` 类样本不足 2000 怎么办？**
当前数据**并未出现**该情况：教育类原始 2,737 条，标题去重后可用 2,704 条，高于目标 2,000 条
（余量 35.2%），已按等距抽样取满 2,000 条。若将来调整采集区间导致不足，程序会如实统计，
不会补造数据；此时可用 `--max-per-class` 对其他类下采样以平衡，或在实验中说明类别不均衡并
采用类别权重 / 过采样处理。质量报告中的「已知限制」一节由实际统计量生成，不会与统计表冲突。

**Q：中途中断会重复采集吗？**
不会。已完成日期记录在 `state/checkpoint.json`，逐日切片保存在 `state/raw_parts/`，重跑自动跳过。

**Q：能否采集正文？**
本程序刻意不采集正文。若后续需要正文，应另行评估版权与站点条款，不建议在课程作业中扩大采集范围。
