# 中国新闻网历史新闻标题采集

面向机器学习课程实验「基于 TF-IDF 特征降维与 BP 神经网络的中文新闻分类研究」的数据采集程序。
数据来源为中国新闻网（中新网）历史滚动新闻归档页，仅采集**标题与元数据**，不采集正文。

---

## 1. 数据来源与合规说明

| 项目 | 说明 |
|---|---|
| 站点 | 中国新闻网 `www.chinanews.com` |
| 页面 | 历史滚动新闻归档页 |
| URL 模板 | `https://www.chinanews.com/scroll-news/YYYY/MMDD/news.shtml` |
| robots.txt | 仅禁止 `/AboutUs/Staff/`、`/part/`、`/iframe/`、`/test`、`/ceshi/`、`/ad/` 等路径；`/scroll-news/` **未被禁止** |
| 访问策略 | 单线程、串行请求，默认间隔 1.2s + 随机抖动；超时 25s；失败最多重试 3 次（指数退避） |
| 反爬处理 | 不绕过验证码、不伪造登录态、不切换代理。若站点返回 403/429 或结构异常，程序记录并停止该日采集，不尝试绕过 |
| 内容范围 | 仅标题、分类标签、发布时间、链接、归档日期、来源；**不下载正文、不下载图片** |

> 该 URL 模板已由站点自身 `js/calendar.js` 中的跳转逻辑验证（`/scroll-news/year/monthday/news.shtml`），
> 页面右侧「查看往日回顾」日历即按此规则生成链接，归档可回溯至 2004 年。

## 4. 快速开始

### 4.1 阶段一：单页结构探测（推荐首次运行）

```bash
python main.py probe --date 2025-01-01
```

输出：终端打印前 10 条解析结果；生成 `reports/stage1_structure_analysis.md`
（含 HTTP 响应、列表容器定位依据、字段选择器、链接指向性校验、分页与历史入口结论）。

### 4.2 阶段二：小规模测试（7 天）

```bash
python main.py all --start 2025-01-01 --end 2025-01-07
```

### 4.3 阶段三：正式采集（默认 2025-01-01 ~ 2026-10-31）

```bash
python main.py all --start 2025-01-01 --end 2026-10-31 --max-per-class 2000
```

### 4.4 分步执行

```bash
python main.py crawl --start 2025-01-01 --end 2026-10-31   # 仅采集
python main.py clean --max-per-class 2000                  # 仅清洗+统计+出图
```

### 4.5 断点续采

程序默认续采：已成功采集的日期写入 `state/checkpoint.json`，并在 `state/raw_parts/` 保留逐日切片。
中断后重新执行相同命令即可跳过已完成日期。

```bash
python main.py all --start 2025-01-01 --end 2026-10-31        # 续采（默认）
python main.py all --start 2025-01-01 --end 2026-10-31 --no-resume   # 强制重采
```

> 修改区间后无需手动清理断点：程序按日期粒度判断，区间内的旧日期仍会复用。

## 5. 命令行参数

| 参数 | 适用子命令 | 默认值 | 说明 |
|---|---|---|---|
| `--date` | probe | 2025-01-01 | 探测的单日归档页 |
| `--start` | crawl / all | 2025-01-01 | 起始日期（含），格式 `YYYY-MM-DD` |
| `--end` | crawl / all | 2026-10-31 | 结束日期（含） |
| `--delay` | crawl / all | 1.2 | 相邻请求间隔秒数，下限由程序校验建议不低于 1.0 |
| `--max-per-class` | clean / all | 0 | 每类样本上限；0 表示不限制。超限时按归档日期**等距抽样**，结果确定可复现 |
| `--outdir` | 全部 | `dataset/` | 输出数据目录；用于隔离测试集与正式集 |
| `--reportdir` | 全部 | `reports/` | 输出报告目录 |
| `--no-resume` | crawl / all | 关闭 | 忽略断点重新采集 |
| `-v, --verbose` | 全部 | 关闭 | 输出调试日志 |

隔离小规模测试集与正式集的做法：

```bash
python main.py all --start 2025-01-01 --end 2025-01-07 \
    --outdir dataset/test_7days --reportdir reports/test_7days
```

## 7. 网页结构要点（实测，勿凭经验修改）

```
div.content_list > ul > li
    ├── div.dd_lm     分类标签，形如 [ 社会 ]；部分为纯文本如 [其他]，无 <a>
    ├── div.dd_bt > a 标题文本 + 文章链接（相对路径）
    └── div.dd_time   发布时间，形如 1-1 23:21（无年份、无补零）
```

四个必须注意的坑：

1. **编码**：响应头未声明 charset（默认被 requests 判为 ISO-8859-1），实际为 UTF-8，必须显式指定，否则中文乱码。
2. **分类取值**：`[其他]` 等标签不含 `<a>`，若用 `div.dd_lm > a` 取值会漏，必须取 `dd_lm` 文本并剥离方括号与空白。
3. **空占位**：列表中存在大量空 `<li></li>`（分隔线），须按「是否有标题链接」过滤，不能按 `<li>` 数量计条数。
4. **无分页**：单页即单日全量；若某日出现 `.pagebox`，程序会告警提示当日可能不完整。

链接形态（均为具体内容页，非栏目首页）：

| 类型 | 形态 | 数字 ID 位数 |
|---|---|---|
| 图文新闻 | `/gj/2025/01-01/10346216.shtml` | 8 |
| 高清图集 | `/tp/hd2011/2025/01-05/1136408.shtml` | 7 |
| 视频 | `/sh/shipin/cns/2025/01-01/news1009460.shtml` | 7（`news` 前缀） |

## 8. 清洗规则

1. 标题规范化：去除零宽字符、BOM、`\r\n`，折叠连续空白，去首尾空格；**不删标点、不改写、不截断**。
2. 删除空标题。
3. 删除非内容页链接（栏目首页、专题页等），仅保留数字 ID 结尾的内容页。
4. 校验发布时间格式，并校验「月-日」与归档日期一致，不一致则记录并剔除。
5. 按规范化 URL 去重（保留首次出现）。
6. 辅助检查 URL 不同但标题完全相同的记录，保留首条并在报告中计数。
7. 类别映射：仅保留映射到目标六类的记录；`unknown`（无分类）一律剔除。
8. `--max-per-class` 配额截断采用按日期等距抽样，避免时间分布偏斜。

## 9. 分类映射说明（重要）

站点滚动列表的原始标签共 20 余种，与目标六类并非一一对应：

| 目标类 | 原始标签 | 说明 |
|---|---|---|
| 财经 | 财经 | 直接对应 |
| 体育 | 体育 | 直接对应 |
| 文娱 | 文化 | **代理映射**：站点不存在「文娱」标签，文娱内容统一标记为「文化」 |
| 教育 | 教育 | 直接对应，但属长尾类别 |
| 社会 | 社会 | 直接对应 |
| 国际 | 国际 | 直接对应 |

未纳入的原始标签：`图片`、`视频`（媒体形态而非主题）、`国内`、`时政`、`湾区`、`华人`、
`健康`、`生活`、`理论`、`法治`、`一带一路`、`国是`、`东西问`、`其他` 等。
原始标签全部保留在 `raw_category` 字段与报告第 4 节，便于核查。

> 若需改为其他映射方案，只需修改 `config.py` 中的 `CATEGORY_MAPPING` 与 `TARGET_CATEGORIES`，
> 无需改动采集与清洗逻辑。

## 10. 代码结构

| 文件 | 职责 |
|---|---|
| `config.py` | 全部结构性常量：URL 模板、选择器、限速与重试参数、分类映射、路径 |
| `crawler.py` | URL 构造与规范化、带重试/限速的请求、归档页解析、时间合成 |
| `cleaner.py` | 标题规范化、去重、类别映射、配额抽样 |
| `quality.py` | 统计、图表、JSON/Markdown 报告生成 |
| `main.py` | 命令行入口（probe / crawl / clean / all）、断点续采、日志 |

请求、解析、清洗、保存相互独立，可单独调用；解析层不写盘，清洗层不发请求。

## 11. 常见问题

**Q：某天返回 404 怎么办？**
该日无归档页（如非法日期 `2025-02-30` 或未归档的未来日期）。程序记入 `crawl_report.json`
的 `days` 列表（`result: not_found`），不重试、不计入错误。

**Q：`教育` 类样本不足 2000 怎么办？**
如实统计，不补造数据。该类日均产量低，属长尾类别。可用 `--max-per-class` 对其他类做下采样以平衡，
或在实验报告中说明类别不均衡并采用类别权重 / 过采样处理。

**Q：中途中断会重复采集吗？**
不会。已完成日期记录在 `state/checkpoint.json`，逐日切片保存在 `state/raw_parts/`，重跑自动跳过。

**Q：能否采集正文？**
本程序刻意不采集正文。若后续需要正文，应另行评估版权与站点条款，不建议在课程作业中扩大采集范围。
