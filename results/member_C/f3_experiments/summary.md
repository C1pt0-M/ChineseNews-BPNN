# F.3 扩充实验：数据质量准入复核

## 结论

**暂不构建扩充训练集，也不启动训练。** 教育类 371 条候选中，有 129 条可从中新网公开索引返回的原文文本直接匹配日期和分钟；其余 242 条本轮未取得可确认日期的原文证据。即便把这 129 条全部视为类别合格，可通过完整质量准入的数量上限仍小于 F3-A 所需的 160 条。129 不是最终通过数量：类别语义和其他质量问题仍需逐条确认。未核实不等于记录错误。

本次按任务的门槛停止，未生成 F3-A / F3-B、未修改标签、未运行模型训练，也未访问测试集指标。保留原验证集及测试集划分。

## 教育类逐条数据与时间

- 全部 371 条候选的 ID、URL、发布时间、归档日能与恢复的原始记录一一对应；对原始标题应用项目 `cleaner.clean_title` 后一致。原始栏目均按现行映射得到教育，文章链接均为原采集记录中的链接。
- 371 条的文章 URL 日期部分与归档日一致，归档时间字段也可追溯。但 URL 路径和归档页不是对真实发表时间的充分证明，不能据此将记录标为审核通过。
- 对 371 条查询公开索引，并对未匹配项做单条补查：129 条匹配相同原文 URL 且索引文本显示与记录一致的日期和分钟；242 条没有取得此类匹配。搜索无匹配不证明原文不存在或日期错误。原始逐条结果和时间证据见 `education_online_evidence.jsonl`，汇总和候选信息见 `education_evidence.csv`。
- 直接访问原站时，沙箱网络代理拒绝连接；取得联网授权后读取 robots.txt 和教育文章页均发生 TLS `UNEXPECTED_EOF_WHILE_READING`。浏览工具直接打开也未成功，但部分原站文章可从公开索引查到。例如 [北京出台20条措施推进中小学科学教育](https://www.chinanews.com/edu/2025/01-03/10347099.shtml) 的原站索引文本显示 2025-01-03 15:48，与该候选记录一致。未尝试绕过访问控制或关闭证书校验。
- 恢复数据的 `source` 字段表示采集站点，不保证文章的原创媒体均为中新网；部分原文索引显示其他转载来源。逐条语义和转载来源核验未完成。

教育栏目标题中存在需要进一步判读的跨主题例子，如“2025精品消费月活动取得积极成效”“中国-孟加拉国板球友谊赛在杭举行 推动板球运动发展”。它们被列为待复核，**未被自动改标签或断定标签错误**。另外，当前尚未形成完整的逐条教育语义审核通过名单，所以不能把已匹配日期的 129 条直接当成合格数量。

## 其他五类分层抽查

从财经、体育、文娱、社会、国际各按月随机抽取 1 条，固定抽样种子 42，共 60 条；样本与月份、来源、标题及状态见 `other_categories_sample.csv`。候选池各类每月均有记录，分布不均：例如体育在 2025-01 为 297 条、2025-11 为 804 条；教育在 2025-01 为 16 条、2025-09 为 53 条。完整逐月数量见 `quality_counts.json`。

抽查中列出财经竖屏剧、社会类留学生文化寻访、国际类气候模型研究等潜在跨主题例子，见 `category_watchlist.csv`。这些仅是标题层面的疑点，不足以判定错误；体育、文娱抽样也不能据此证明整类无标签问题。原有栏目映射没有改变。

## 重复风险和基准冲突

- 对 371 条教育候选重新与 train/val/test 的 ID、规范化 URL、规范化标题及字符三元组 Jaccard ≥ 0.8 比较，均未发现匹配；与其他保守候选也未发现达到该阈值的高相似项。测试集仅使用 ID、URL、标题和时间进行排重，没有使用类别标签或指标。
- 原训练集内重新检出 4 对高相似标题，涉及 5 条：其中 1 对涉及同一亚冬会旗手消息，另 3 对是安徽、四川、湖北高考分数线标题之间的相似性，可能是不同事件。见 `baseline_near_conflicts.csv`；未从原训练集删除记录。
- 此前恢复数据与基准的 1 组规范化标题相同但栏目类别不同的记录仍保留在 `../f3_recovery/analysis/train_label_conflicts.csv`，不修改任一标签。上述基准近重复和标签歧义在 F2 与 F3 比较中会共同存在；高相似规则既可能误报，也不能排除语义改写或同一事件不同标题。

## 基准与未执行的实验

已有 F2 seed 42 使用 6,549 条训练样本，验证 Macro-F1 **0.78467**、Accuracy **0.78329**、最佳 epoch **9**；社会→财经 **90** 条，社会→文娱 **79** 条。完整类别指标和训练曲线保存在 `../f2_formal_word_char/F_word_char_s42/`。本次没有新的 F3 指标、损失曲线或训练耗时，不能推断扩充是否会改善表现。

若后续能恢复原文访问，应先对未核实的 242 条继续取得原站日期证据，逐条审查教育语义及来源，再按同一去重标准重新计算通过数量。若达到 160 才可考虑 F3-A；达到 319 才可考虑 F3-B。若实际通过数量仍不足，则继续停止扩充实验。

## 文件和复现

- `quality_review.py`：核对候选与原始记录、映射、URL 日期，并生成教育清单及其他类分层抽样。
- `education_evidence.csv`、`education_online_evidence.jsonl`：371 条教育候选和逐条公开索引检查结果；匹配状态仅表示日期时间证据，非整体质量批准。
- `quality_counts.json`、`other_categories_sample.csv`、`category_watchlist.csv`：类别月份分布、抽查及需进一步核对的标题。
- `check_duplicates.py`、`duplicate_recheck.json`、`baseline_near_conflicts.csv`：重复复核与基准冲突依据。

所有产物独立于既有数据划分。未执行 git add、commit、push 或远端同步。
