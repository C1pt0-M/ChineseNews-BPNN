# F.3 官方归档复核与 F3-A 结果更正

## 结论与更正

官方时间证据已补齐，但**本次唯一一次 F3-A 训练不能作为通过全部准入检查的正式结果**。训练启动后，更宽的同事件筛查发现：初版新增样本中有 5 条与原训练集可能描述同一事件，另有 2 条可能重复报道同一次税收数据发布。这些记录需要排除或人工核实；因此训练在完整同事件检查之前启动，是本次流程错误。

初版运行的验证 Macro-F1 是 **0.78729**，相对 F2 seed 42 的 0.78467 为 **+0.00262**。该数值及后文指标只保留为**不合格初版的诊断记录**，不能作为干净受控实验的结论。原始训练产物未覆盖或删除。

已在独立目录生成修订候选 `f3_a_dataset_v3/`，排除上述 7 条并补足类别配额；**修订版未训练，最终训练准入仍待审核**。按用户限定的本阶段一次训练次数，不擅自重复训练，等待审核决定。修订版额外弱词面规则仍标出 23 对标题层面的相似记录；本轮根据日期、地点、人物或比赛项目差异初判为不同事件，但这不是原文级事实核验，明细仍需审核，见 `f3_a_v3_event_review.csv`。

## 主要限制与下一步

- 修订版的 23 对较弱词面相似记录仅经标题层面判断，应由审核者确认；字符相似度也不能排除不同措辞描述同一事件。
- 固定关键词形成的审阅池与社会类月份补位使主题和时间分布发生变化，规模与样本内容效应不能分开。
- B 级归档时间满足本次批准的证据标准，但不等于逐篇独立核实文章正文发布时间。
- 原有 6,549 行保留导致其历史近重复与标签歧义继续存在。

未经审核，不对修订版启动第二次训练；未运行 F3-B、五随机种子或测试集模型评估，也未执行 git add、commit、push 或远端同步。
