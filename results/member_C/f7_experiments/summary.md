# F.7 BP 参数 2×2 对照

四组均使用 F3-A 正式训练集 7,531 条、原验证集 3,184 条和词 7,000 + 字 3,000 的 F6-B 特征。F7-0 复用 F6-B 五种子；其他三组由 F.7 独立入口调用原 run_single 和 trainer。
BP 为单隐层：输入 → 线性层（宽度 hidden）→ ReLU → Dropout → 六类输出线性层；层数不变。Adam、weight_decay=0.0001、batch=64、max_epochs=100、patience=10、min_delta=0.0001、grad_clip=5.0；ReLU，隐藏 dropout=0.2，input dropout=0。

## F.8 候选问题

在确定是否采用更大隐藏层或更高学习率之前，可检查主要混淆类别的配对预测转变与训练、验证损失曲线，评估容量、收敛与过拟合迹象；另需在不更改既有验证标签的条件下规划独立泛化验证。此处仅提出问题，不启动新实验。

## 基于本轮结果的技术观察

- 隐藏宽度从 64 增至 256：学习率 0.0003 时，Macro-F1 的平均配对差为 -0.00140；学习率 0.001 时为 -0.00257。这只描述当前固定数据与五个种子。
- 学习率从 0.0003 增至 0.001：宽度 64 时平均差为 -0.00022，宽度 256 时为 -0.00139；交互差中之差为 -0.00116。种子数少，不能仅凭数值断言交互显著。
- F7-3 在最佳 Macro-F1 轮的训练/验证损失均值为 0.29597/0.62760；到停止轮分别为 0.04176/0.80458。训练损失下降、验证损失上升是后续轮出现过拟合的迹象，不证明单一成因。早停按 Macro-F1 选模，而不是按最小验证损失。

F.8 可具体考察固定 64 隐藏单元和 F6-B 特征时，改变单一正则化强度是否缩小训练与验证损失差距；应先固定比较水平、种子和选模方式，并在训练集内部做参数选择。另可按社会→财经与相反方向逐标题对齐预测转变，区分决策边界变化和类别 F1 的总体变化。以上仅为候选问题，不在本轮训练。
