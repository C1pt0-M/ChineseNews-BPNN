# F.3 + F.4 阶段结果

F.3：正式审核版保留原 6,549 条、增加 982 条，seed 42 验证 Macro-F1 0.78950，相对同 seed F2 0.78467 变化 +0.00483；社会→财经 90→88，社会→文娱 79→75。仅一次运行，主题与词表亦有变化，仍需判断稳定性。详细准入和事件审核见 `f3_analysis/f3_final_review.md`。

F.4：训练集内无泄漏五折选参后，LinearSVC 的 C=0.1、验证 Macro-F1=0.77540；LogisticRegression 的 C=1、验证 Macro-F1=0.77256，均低于 F2 BP seed 42 的 0.78467。详细类别与混淆矩阵见 `classic_baselines/summary.md`。

两种线性方法在当前特征和 C 网格下未超过 BP，但比较不能证明 BP 已达上限。社会类仍相对困难；类间语义重叠、标注差异、训练特征及样本量可能共同影响结果，现有实验不足以分离各因素。BP 使用验证集早停，而经典模型 C 用训练折选择，也需注意比较口径。

建议下一阶段先由研究负责人决定是否对审核版扩充数据进行五随机种子复现，并针对社会类错误开展内容与标注审计；现有结果尚不能支持对 0.85 可达性的承诺。未使用测试集指标，未启动其他架构或额外参数搜索。
